# 1. Database Schema & Supabase Configuration
Generate the SQL script or explain the precise setup for the following Supabase tables. Apply Row Level Security (RLS) to all tables.

Table 1: `profiles`
- `id` (uuid, references auth.users, primary key)
- `email` (text)
- `role` (text, default 'user', can be 'admin')
- `current_question` (integer, default 1)
- `last_submission_time` (timestamp with time zone, default now())
* RLS: Users can only read/update their own profile. Admins can read all.

Table 2: `questions`
- `id` (integer, primary key, represents question number)
- `desk_string` (text, e.g., "Desk 402-B")
- `image_url` (text, link to the clue image)
- `valid_answers` (text array, e.g., ['answerone', 'answertwo'])
* RLS: Users can only read the row where `id` equals their `current_question`. Admins can read/write all.

Table 3: `announcements`
- `id` (uuid, primary key)
- `message` (text)
- `created_at` (timestamp with time zone, default now())
* RLS: Everyone can read. Only Admins can insert/update/delete.

# 3. Core Application Logic & Data Flow

A. User Normalization & Validation (The Answer Engine):
- When a user submits an answer, create a utility function that formats their input:
  `const normalizeString = (str: string) => str.toLowerCase().replace(/\s+/g, '');`
- Compare the normalized input against the `valid_answers` array for their `current_question`.
- If correct: Trigger a Server Action or Supabase RPC to increment their `current_question` by 1 and update their `last_submission_time` to the exact current timestamp.

B. The Leaderboard Logic:
- Fetch all profiles.
- Format the display name: split the email at '@' and return the first part (e.g., `xyz@google.com` becomes `xyz`).
- Sorting Rule 1: Sort by `current_question` in descending order (highest question wins).
- Sorting Rule 2 (Tie-breaker): If users are on the same question, sort by `last_submission_time` in ASCENDING order (whoever got there first wins).
- CRITICAL: Do NOT render or display the `last_submission_time` in the UI.

C. Real-time Announcements:
- Use Supabase Realtime to subscribe to the `announcements` table. When an admin posts a new hint, it should appear instantly on the user's dashboard without a page refresh.
